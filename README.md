# Promation

An open-source 2D animation application: vector drawing, bone rigging and
keyframe animation. Desktop first (Linux, Windows, macOS), with an Android
tablet version sharing the same core later.

Written in [Odin](https://odin-lang.org). Licensed under the GPL-3.0-or-later (see `LICENSE`).

> Status: **Phase 0**, a technology test. Nothing here is usable for animation yet.
> See [docs/PLAN.md](docs/PLAN.md) and [docs/phase0.md](docs/phase0.md).

## Requirements

- Odin (dev-2026-10 or newer)
- SDL3 (3.4+) development files
- `glslc` (shaderc) to compile shaders to SPIR-V
- A Vulkan-capable GPU (Metal/D3D12 come later via shader cross-compilation)
- To build Dear ImGui once: git, python3 (venv + pip), a C++ compiler

On Arch Linux: `pacman -S odin sdl3 shaderc vulkan-icd-loader python`

## Building

```bash
./scripts/build_imgui.sh   # once: builds Dear ImGui + Odin bindings into third_party/
./build.sh                 # debug build -> build/promation
./build/promation
```

Other modes:

```bash
./build.sh test      # unit tests + headless GPU render -> build/render_test.png
./build.sh release   # optimised build
./build.sh check     # type-check all packages
```

## Layout

```
src/app/          application: window, input, ImGui panels (package main)
src/render/       GPU vector renderer + curve/stroke geometry
src/tools/        developer tools (headless render test)
shaders/          GLSL sources, compiled to SPIR-V into build/shaders/
scripts/          dependency build scripts
third_party/      vendored bindings (generated by scripts/build_imgui.sh)
docs/             plan and design notes
```
